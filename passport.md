# Паспорт приложения и платформы

## Приложение

- Название: Notes API.
- Назначение: создание и чтение учебных текстовых заметок.
- Пользователи: студенты учебной группы.
- Входы: HTTP-запросы и JSON `{"text":"..."}`.
- Выходы: JSON-ответы и HTTP-коды.
- Версия: `1.0.0`; образ: `notes-api:1.0.0`.
- Компоненты: Python 3.13, Docker, Docker Compose v2.
- Данные: `/data/notes.json` в именованном томе `notes-api-data`.
- Журналы: стандартный вывод контейнера, ротация 3 файла по 10 Мбайт.
- Секреты: отсутствуют.

## Целевая платформа

- ОС: Linux с Docker Engine и Compose v2.
- Архитектура: x86-64 или ARM64 при сборке образа на целевой платформе.
- Ресурсы контейнера: 0,5 CPU, 128 Мбайт RAM.
- Порт: 8201/TCP, переопределяется переменной `PORT`.
- Запуск после перезагрузки: политика `unless-stopped`.

## Критерии приёмки

1. `/health` возвращает HTTP 200 и `healthy`.
2. Запись создаётся через `POST /notes`.
3. Созданная запись читается после перезапуска контейнера.
4. Некорректный запрос возвращает HTTP 400 или 404.
5. Контейнер имеет статус `healthy` и соблюдает лимиты ресурсов.
